# @aazucena/utils

📍 **Part of the [AAZUCENA Monorepo](../../README.md)**

## Overview
Pure utility functions with zero dependencies on UI frameworks.

## Responsibility
- String manipulation (slugify, truncate).
- Date formatting and relative time calculation.
- Number and currency formatting.
- DOM and functional helpers (cn, debounce).

## Usage
```typescript
import { cn } from '@aazucena/utils/dom';
```
