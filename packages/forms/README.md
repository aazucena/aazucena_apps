# @aazucena/forms

📍 **Part of the [AAZUCENA Monorepo](../../README.md)**

## Overview
Form management system built on react-hook-form and Zod.

## Responsibility
- Shared form field components (TextField, TextArea, etc.).
- Multi-step form state machines.
- Validation logic integration.
- Intelligent Inquiry Firewall (Gated Scheduling) integration.

## Usage
```typescript
import { Form, TextField } from '@aazucena/forms';
```
