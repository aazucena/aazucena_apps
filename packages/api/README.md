# @aazucena/api

📍 **Part of the [AAZUCENA Monorepo](../../README.md)**

## Overview
Standardized API clients, Zod validators, and data transformers.

## Responsibility
- Centralized fetch clients with error handling.
- Zod runtime validation schemas.
- Data transformation layer for CMS and Analytics.
- Mock data providers for testing.

## Usage
```typescript
import { portfolioClient } from '@aazucena/api/clients';
```
