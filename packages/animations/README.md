# @aazucena/animations

📍 **Part of the [AAZUCENA Monorepo](../../README.md)**

## Overview
Animation utilities and presets for GSAP, Three.js, and PixiJS.

## Responsibility
- GSAP entrance and transition presets.
- Three.js geometry and material helpers.
- PixiJS particle system configurations.
- ScrollTrigger orchestration logic.

## Usage
```typescript
import { fadeIn } from '@aazucena/animations/gsap';
```
