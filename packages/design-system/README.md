# @aazucena/design-system

📍 **Part of the [AAZUCENA Monorepo](../../README.md)**

## Overview
Centralized design tokens and theme configuration for the aazucena ecosystem.

## Responsibility
- OKLCH color scales and semantic tokens.
- Typography scales and font families.
- Spacing, shadows, and z-index systems.
- Tailwind CSS presets and Figma token exports.

## Usage
```typescript
import { colors, spacing } from '@aazucena/design-system/tokens';
```
