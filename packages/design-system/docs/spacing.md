# Spacing System

## 4px Baseline Grid

The monorepo uses a strict **4px baseline grid**. All margins, paddings, and component dimensions must be multiples of 4.

## Scale

- `1`: 4px
- `2`: 8px
- `4`: 16px
- `8`: 32px
- `16`: 64px

## Container Guidelines

The max-width for content containers is restricted to `1200px` (`max-w-container`) to ensure readability on wide displays.
