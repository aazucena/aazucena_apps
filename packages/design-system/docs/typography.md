# Typography System

## Font Families

- **Sans-Serif:** `Fira Sans` - Used for all readable content, descriptions, and labels.
- **Monospace:** `Fira Code` - Used for all technical data, telemetry streams, and terminal outputs.

## Type Scale

We use a mathematical scale for consistency:

- `h1`: 32px (Bold)
- `h2`: 24px (Bold)
- `body`: 16px (Regular)
- `terminal`: 12px (Medium)
- `tiny`: 10px (Black)
