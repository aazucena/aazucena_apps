# @aazucena/icons

📍 **Part of the [AAZUCENA Monorepo](../../README.md)**

## Overview
Centralized icon system using @mynaui/icons-react.

## Responsibility
- Icon registry and lookup service.
- Standardized Icon component.
- IconButton patterns.
- SVG path management for animations.

## Usage
```typescript
import { Icon } from '@aazucena/icons';
```
