# @aazucena/hooks

📍 **Part of the [AAZUCENA Monorepo](../../README.md)**

## Overview
A library of reusable React hooks categorized by domain.

## Responsibility
- Device capability detection (media queries, performance tiers).
- State management helpers (local storage, debouncing).
- Animation orchestration hooks.
- Data fetching and subscription hooks.

## Usage
```typescript
import { useDeviceCapabilities } from '@aazucena/hooks/device';
```
