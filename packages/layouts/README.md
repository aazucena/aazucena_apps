# @aazucena/layouts

📍 **Part of the [AAZUCENA Monorepo](../../README.md)**

## Overview
Shared layout components for Astro and React.

## Responsibility
- Base layout structures (BaseLayout, DashboardLayout).
- Reusable section wrappers.
- Grid and container components.
- Responsive layout templates.

## Usage
```typescript
import { SectionLayout } from '@aazucena/layouts/react';
```
