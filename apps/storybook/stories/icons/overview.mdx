# Icons

The **@aazucena** icon system is a unified protocol for delivering high-fidelity vector assets across the monorepo. It combines the clean, technical aesthetic of **Myna UI Icons** with custom brand-specific marks and pixel-perfect simple icons.

---

## 🏗️ Icon Architecture

Our icon system operates on a **Single Entry Point** model. All applications utilize the `@aazucena/icons` package, which provides:

1.  **Registry-Driven Logic:** A central registry that maps strings to components for dynamic rendering.
2.  **Custom Asset Support:** Hand-crafted SVG components for brand-specific needs (Astro, React, Vite, etc.).
3.  **SimpleIcons Integration:** Pre-configured aliases for common dev-tool logos with standardized casing.
4.  **CMS Resilience:** Built-in support for direct SVG injection from Strapi content fields.

---

## 🚀 Usage Protocol

### 1. Registry-Based Usage (Recommended)
For dynamic content (CMS data, navigation arrays) where the icon name is provided as a string.

```tsx
import { getIconComponent } from '@aazucena/icons';

const MyIcon = ({ name }) => {
  const Icon = getIconComponent(name);
  
  if (typeof Icon === 'string' && Icon.startsWith('<svg')) {
    return <div dangerouslySetInnerHTML={{ __html: Icon }} className="w-6 h-6" />;
  }
  
  return <Icon size={24} className="text-primary" stroke={1.5} />;
};
```

### 2. Direct Component Usage
For internal development or when the icon is strictly known at compile-time.

```tsx
import { Code, Terminal } from '@mynaui/icons-react';

export const MyComponent = () => (
  <div className="flex gap-4">
    <Code size={24} stroke={2} />
    <Terminal size={24} stroke={2} />
  </div>
);
```

## 🛡️ Technical Standards

| Metric | Standard |
|---|---|
| **Primary Library** | `@mynaui/icons-react` (v0.4.2) |
| **Brand Library** | `@icons-pack/react-simple-icons` |
| **Stroke Width** | Default: `1.5` / Technical: `2.0` |
| **Standard Sizes** | `16`, `20`, `24`, `32`, `48` |
| **Color Protocol** | `fill='none' stroke='currentColor'` (UI Icons) |
| **Format** | Pure React Components (SVG-in-JS) |
