# System UI Library (MynaUI)

Our functional UI iconography is powered by **MynaUI**. These are stroke-based, mathematical icons designed for clarity at small sizes. They are used for navigation, standard actions, and system status signaling.

## 🏗️ Stroke Weight Protocol

The MynaUI set is specifically chosen for its consistent stroke weights. We enforce two primary tiers depending on the UI context.

## Technical Specifications

| Property | Standard |
|---|---|
| **Source Library** | `@mynaui/icons-react` |
| **Logic** | Stroke-based (Path outlines) |
| **Default Stroke** | `1.5` |
| **Aesthetics** | Geometric, Minimalist, Open-counter |
