This library contains the unique visual marks and hand-crafted implementations that define the **@aazucena** digital identity. Unlike standard library icons, these assets are proprietary or custom-engineered for specific creative protocols.

## Technical Specifications

| Property | Implementation |
|---|---|
| **Format** | Pure React Components (SVG-in-JS) |
| **Coloring** | `fill='currentColor'` or `stroke='currentColor'` |
| **Scaling** | Fully vector-based, supports numeric `size` prop. |
| **Logic** | Registered in `@aazucena/icons/registry`. |
