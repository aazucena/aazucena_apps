## Technical Specifications

| Property | Implementation |
|---|---|
| **Format** | Pure React Components (SVG-in-JS) |
| **Coloring** | `fill='currentColor'` or `stroke='currentColor'` |
| **Scaling** | Fully vector-based, supports numeric `size` prop. |
| **Logic** | Registered in `@aazucena/icons/registry`. |
