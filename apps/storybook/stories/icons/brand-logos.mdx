# Tech & Social Library

Our technical and social logos are powered by **SimpleIcons**. Unlike our UI set, these are `fill`-based icons that represent external brands and developer tools.

---

## 🏗️ The Dual-State Protocol

We maintain two naming conventions for every brand icon to support both **Official Brand Identity** and **Dynamic Vibe Integration**.

### 1. The Chameleon State (Theme-Reactive)
Uses the default name (e.g., `GitHub`). These icons ignore their official brand colors and instead use `fill='currentColor'`, allowing them to adapt to the active **Vibe**.

### 2. The Constant State (Official Hex)
Uses the `*Hex` suffix (e.g., `GitHubHex`). These icons are hard-coded to their official brand colors and do not change with the Vibe.

## Technical Specifications

| Property | Standard |
|---|---|
| **Source Library** | `@icons-pack/react-simple-icons` |
| **Logic** | Fill-based (Path solids) |
| **Official Colors** | Accessible via `*Hex` export suffix. |
| **Naming Protocol** | PascalCase aliases for standardized dev-tool access. |
