# Charts & Graphs

The **`@aazucena/visualizations`** package provides 21 high-performance, D3-powered visualization components built for the portfolio monorepo.

## Architecture

Every chart follows a composable anatomy:

```
ChartContainer          // Root wrapper (border, rounded, hover effect)
  ChartHeader           // Title row + toolbar area
    ChartTitle          // Bold uppercase heading
    ChartDescription    // Muted subtext
    ChartToolbar        // Export controls (SVG / PNG / CSV)
  ChartContent          // Main SVG rendering area
  ChartFooter           // Legends, metadata
```

All primitives are exported from `@aazucena/visualizations` and can be used independently.

## Hook Pattern

Every chart has a companion `use[Chart]` hook that encapsulates D3 bindings, scales, and resize logic:

```tsx
import { useBarChart } from '@aazucena/visualizations';

const { svgRef, dimensions } = useBarChart(data, options);
```

Hooks are useful when you need direct control over the SVG or want to compose charts into custom layouts.
