# Avra Design System

A comprehensive, token-driven component library for the Aldrin Azucena portfolio monorepo.
Built with React 19, Tailwind CSS 4, and Radix UI primitives.

---

## The Name

**Avra** — pronounced **AH-vra** — did not begin as a name. It emerged from a mark.

The brand logo is the double initial **AA**, intersected by a thunderbolt. Read in visual sequence, those strokes resolve to **AVA** or **AVRA**. The name was already there; it just needed to be seen.

The etymology reinforces what that mark implies. In **Greek**, αύρα means *breeze*, *ocean breeze*, or *breath of air* — something light and in motion, present but never heavy. In **Hebrew**, the root *Avrah* carries the sense of *crossing over* or *father of many*, and is also interpreted simply as *air* or *environment*. Both readings point toward the same quality: something that fills a space without dominating it.

That is the intent of the design system. Avra is infrastructure — a shared environment that every application in the monorepo breathes through. It should feel like a tailwind: invisible when it's working, immediately noticed when it's absent.

---

## The visual language: instrument in air

Avra 0.2 balances two readings of the name. The data is an instrument: mono labels, live status, dense readouts. The frame around it is air: generous gutters, surfaces separated by tone instead of boxes, light display numbers, slow motion.

- **Surfaces:** ink neutrals (hue ~228). Panels sit one tone step off the background; hairline rules only where structure needs them. No shadows, no blur.
- **Shape:** 6px panels and cards, 4px controls and badges, shared by every vibe.
- **Color roles:** `signal` cyan for data and focus, `success` mint, `warning` amber, `alert` coral. Warning always carries ◆ and alert always carries ▲, so status never depends on color alone.
- **Type:** Fira Sans for reading and Light display metrics; Fira Code for labels (`TRAFFIC // 30D`), values and code.
- **Motion:** a 4s breathing pulse on live indicators, lines that draw in, 200ms state changes, all off under `prefers-reduced-motion`.

The source of truth is the [Avra Design System Figma file](https://www.figma.com/design/KIKPyhRdGbeBhj8dS0km2G); its variables carry the same names as the CSS custom properties.

## Theming

This Storybook supports two independent controls in the toolbar:

- **Light / Dark** — toggles the `dark` class on `<html>` via `@storybook/addon-themes`
- **Vibe** — applies one of 17 seasonal/style vibes to the story canvas via `ThemeManager`

Both controls are fully independent. You can preview any vibe in either light or dark mode.
