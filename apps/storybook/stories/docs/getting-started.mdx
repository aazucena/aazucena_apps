# Getting Started

## Installation

All packages are internal to the monorepo. Add them as workspace dependencies:

```json
{
  "dependencies": {
    "@aazucena/animations": "workspace:*",
    "@aazucena/ui": "workspace:*",
    "@aazucena/visualizations": "workspace:*",
    "@aazucena/design-system": "workspace:*",
    "@aazucena/icons": "workspace:*",
    "@aazucena/hooks": "workspace:*",
    "@aazucena/utils": "workspace:*",
    "@aazucena/types": "workspace:*"
  }
}
```

## Setup

### 1. Import the stylesheet

One CSS import brings in Tailwind, the generated Avra tokens (`css-vars.css`) and the role utilities:

```css
/* app.css */
@import '@aazucena/ui/globals.css';
```

### 2. Optional: the Tailwind preset

Tailwind 4 reads theme values from CSS, so most apps need nothing else. To reuse the shared preset (dark mode on the `.dark` class, Fira font stacks), point Tailwind at a config that extends it:

```css
@config './tailwind.config.ts';
```

```ts
// tailwind.config.ts
import { tailwindPreset } from '@aazucena/design-system';

export default { presets: [tailwindPreset] };
```

### 3. Light and dark

Dark mode follows the `dark` class on `<html>`. Set it before first paint (a small inline script reading the saved preference) to avoid a flash.

### 4. Generated tokens

`dist/css-vars.css` is generated, not committed. The design-system `build` writes it, and Turborepo builds dependencies first, so apps get it automatically. After changing tokens or themes during development, regenerate it directly:

```bash
pnpm --filter @aazucena/design-system ds:css
```

## Role utilities

Style with the Avra role utilities rather than stock palette classes:

| Utility | Role |
|---|---|
| `bg-background`, `bg-panel`, `bg-panel-raised`, `bg-state` | Surfaces |
| `border-rule`, `border-rule-strong` | 1px rules and control outlines |
| `text-foreground`, `text-muted-foreground`, `text-signal` | Text |
| `rounded-card`, `rounded-control` | 6px and 4px shapes |
| `h-control`, `h-control-sm`, `h-control-lg` | 36, 30 and 44px controls |
| `micro-label` | Fira Code panel labels (`TRAFFIC // 30D`) |

The full rules are on the [Instrument Language](?path=/docs/docs-instrument-language--docs) page.

## Using components

```tsx
import { Button, Card } from '@aazucena/ui';

export function Example() {
  return (
    <Card>
      <Button variant="default">Hello</Button>
    </Card>
  );
}
```

## Using visualizations

```tsx
import { BarChart } from '@aazucena/visualizations';
import type { BarChartData } from '@aazucena/types';

const data: BarChartData[] = [
  { label: 'React', value: 90 },
  { label: 'TypeScript', value: 85 },
];

export function Dashboard() {
  return <BarChart data={data} title="Skills" />;
}
```

Every chart component wraps in `ChartContainer` and includes a built-in export toolbar (SVG / PNG / CSV).
See the **Charts & Graphs** section in the sidebar for live examples.

## Applying a vibe at runtime

```ts
import { applyVibe, resetVibe } from '@aazucena/design-system';

// Apply a seasonal vibe
applyVibe('halloween', 'dark');

// Reset back to baked-in defaults
resetVibe();
```

---

## Package manager

Always use **pnpm**. Never npm or yarn.

```bash
pnpm install
pnpm dev
pnpm build
```
