# Changelog

## Phase 4 — Animation Fidelity & Tooling (2026-02-18)

**Added**

- `ObjectViewer` component — modular 3D inspection tool with professional HUD and interactive controls
- Interactive Inspection Toolbar — environment cycling, FPS/Stats, wireframe, bounding box, and axes helpers
- 3D Capture Engine — integrated screenshot tool with camera shutter flash feedback
- System Notifications — integrated Sonner toast system for camera reset and capture confirmations
- Atmospheric Registry — expanded to 64+ high-fidelity Three.js objects mapped with cost tiers and layers
- High-Fidelity Mechanics — re-engineered ISS solar arrays, E.T. Bike IK pedaling, and Planet Express canon-fidelity
- Flight Profiles — 'Majestic' vs 'Frantic' variants for Bird flapping mechanics with shoulder-joint pivots
- Legal & Fair Use Framework — comprehensive documentation for pop-culture references within the portfolio context

## Phase 4 — Developer Experience (2026-02)

**Added**

- `ThemeManager` class — instance-based vibe application for Storybook canvas isolation
- `applyVibe` / `resetVibe` / `getActiveVibe` / `isValidVibe` — functional runtime theme API
- Vibe toolbar picker in Storybook — 18 vibes switchable per-story without page reload
- CSS variable generation via `generateCssVariables(vibeId)` (build-time)
- Tailwind preset from `@aazucena/design-system`
- Full Storybook suite — 416 stories across 23 sub-categories
- `Charts & Graphs` top-level Storybook category — 21 visualization components with mock data (34 stories)
- Overview MDX documentation page for the `@aazucena/visualizations` package
- MDX documentation pages (Introduction, Getting Started, Design Tokens, Changelog)
- `Result` component — centered block-level status feedback (success, error, warning, info) with 7 sub-components and 10 stories
- `ErrorPageVisual` `status` prop — auto-maps 9 HTTP codes (400–503) to `code`, `label`, and `color` presets
- `errorPageStatusMap` export — introspectable lookup of HTTP status presets for consumer extension
- 7 new StatusPages stories — Error400, Error401, Error403, Error408, Error429, Error502, Error503

**Changed**

- Storybook preview converted to TSX to support JSX decorators
- `storySort` updated to reflect actual category tree
- Four orphaned story titles moved under `Components/` hierarchy
- `ErrorPageVisual` `color` prop type updated from `'rose'` to `'destructive'` for design system consistency
- Existing Error404 and Error500Cyber stories updated to use `status` prop presets
