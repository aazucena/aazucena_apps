# Theme System

The **Avra** design system uses **"Vibes"** to manage high-level visual identities. A Vibe is a master orchestrator that redefines the entire visual and behavioral personality of the application in one unified protocol.

## Technical Architecture

The Theme System operates on a **Constraint-Based Injection** model. Unlike traditional theme engines that rely on global body classes, our system allows for scoped encapsulation.

### Independent Mode Logic
Every Vibe provides independent configurations for both `light` and `dark` modes. This allows the system to maintain visual integrity even when the user forces a specific system-level mode.

| Component | Responsibility |
|---|---|
| **ThemeManager** | The core class that handles the injection of CSS custom properties into a target element. |
| **_theme-core** | Sanitizes values and ensures that only valid tokens are committed to the DOM. |
| **Vibe Registry** | A centralized catalog of all 18 available visual protocols. |

---

## Technical Specifications

| Property | Implementation |
|---|---|
| **Encapsulation** | Scoped via container-level CSS variables (Isolated). |
| **Performance** | Native CSS variable injection (Zero-runtime overhead). |
| **Extensibility** | Atomic Vibe definitions in `packages/design-system/src/themes/`. |
| **Precision** | All color values strictly mapped to the OKLCH brand scales. |
