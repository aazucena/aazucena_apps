# Theme System

A **vibe** is a named set of role values for light and dark mode. Applying one writes those values as CSS custom properties, and every component that uses role utilities picks them up. There are 17 vibes; the [Themes](?path=/docs/design-tokens-themes--docs) page shows them all.

---

## What a vibe can change

| Changes per vibe | Fixed in every vibe |
|---|---|
| Color roles: surfaces, text, signal, status, chart series | Radius (6px panels, 4px controls) |
| Heading font (Fira Sans, Playfair Display or Fira Code) | Control heights, panel padding, spacing |
| Title size and weight | Body font (Fira Sans) |

Light and dark are independent: each vibe defines both, and the `dark` class on `<html>` picks one.

---

## Applying a vibe

**App-wide:** the functional API writes to `<html>`.

```ts
import { applyVibe, resetVibe, getActiveVibe } from '@aazucena/design-system';

applyVibe('halloween', 'dark'); // write the vibe's dark values to <html>
getActiveVibe();                // 'halloween' (read from data-vibe)
resetVibe();                    // remove them; the static css-vars.css defaults apply again
```

**Scoped to an element:** `ThemeManager` targets one container, so two vibes can sit side by side. Storybook uses it for the canvas and for the Themes gallery.

```ts
import { ThemeManager } from '@aazucena/design-system';

const manager = new ThemeManager(element).apply('christmas', 'light');
manager.destroy(); // removes only the properties it wrote
```

Both paths pass values through `sanitizeCssValue` before writing them, so a vibe definition can't inject arbitrary CSS.

---

## Adding a vibe

1. Add `packages/design-system/src/themes/<name>.ts` exporting a `ThemeVibe` with `light` and `dark` configs. Define the roles you change; a vibe only writes the properties it defines, so anything left out keeps the default value from `css-vars.css`.
2. Register it in `themes/registry.ts`.
3. Check it in the [vibe matrix](?path=/story/design-tokens-vibes-matrix--light): text must reach 4.5:1 and UI parts 3:1 in both modes.
4. Add a changeset for `@aazucena/design-system`.
