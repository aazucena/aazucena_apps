# Motion & Animation

Motion in Avra is slow and sparse: state changes are quick, lines draw in, and live indicators breathe. Nothing bounces on a default surface.

---

## Avra motion tokens

| Token | Value | Use |
|---|---|---|
| `--motion-base` | 200ms | State changes: hover, press, toggle, color |
| `--motion-draw` | 900ms | Chart lines and bars drawing in |
| `--motion-breath` | 4000ms | The pulse on live status indicators |

Components currently write `duration-200` directly, which matches `--motion-base`. New work should use the tokens: `duration-[var(--motion-base)]`.

## Easing

| Token | Curve | Use |
|---|---|---|
| `--timing-out` | `cubic-bezier(0, 0, 0.2, 1)` | Things entering: menus, popovers, drawers |
| `--timing-in` | `cubic-bezier(0.4, 0, 1, 1)` | Things leaving |
| `--timing-base` | `cubic-bezier(0.4, 0, 0.2, 1)` | Everything else |

`--timing-authentic` and `--timing-in-out` have the same curve as `--timing-base`.

## Legacy durations

## Springs (Framer Motion)

`springs` from `@aazucena/design-system` holds four presets for Framer Motion. Use `smooth` by default; keep `bouncy` for playful, opt-in moments outside the data UI.

| Preset | Stiffness | Damping | Feel |
|---|---|---|---|
| `smooth` | 260 | 20 | Responsive and stable (default) |
| `snappy` | 300 | 30 | Quick, little overshoot |
| `gentle` | 100 | 15 | Soft arrival |
| `bouncy` | 400 | 10 | Elastic |

## Reduced motion

`@aazucena/ui` respects `prefers-reduced-motion` in two layers:

- **CSS:** one rule in `core.css` stops every CSS animation and transition when the user asks for reduced motion. Durations drop to 0.01ms rather than `none`, so `animationend` still fires and Radix still unmounts closed dialogs and menus. Spinners (`animate-spin`) keep turning because they mean "loading"; add `data-motion="essential"` to anything else that must keep moving.
- **JavaScript:** Framer Motion components wrap their animations in `MotionConfig reducedMotion="user"` (slides, scales and layout motion turn off; short fades stay) or check `useReducedMotion()` for springs and loops. Outside Framer, use `usePrefersReducedMotion()` from `@aazucena/hooks`.

Under reduced motion, coming-soon's text scramble and data stream stop, the wheel picker and reading progress drop their springs, `RinCharacter` shows the static mark, `useTypingEffect` shows the full text and `useFlipText` swaps words without the flip.

A test in `@aazucena/design-system` (`ui-reduced-motion.test.ts`) fails if a new Framer Motion component, interval loop or Rive autoplay skips the check.
