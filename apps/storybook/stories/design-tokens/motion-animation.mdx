## Durations

| Name | CSS Variable | Value | Usage |
|---|---|---|---|
| Fast | `--duration-fast` | `150ms` | Micro-interactions, hover states. |
| Normal | `--duration-normal` | `300ms` | General UI transitions, content swaps. |
| Slow | `--duration-slow` | `500ms` | Page entrances, large component movement. |
| Ultra Slow | `--duration-ultra-slow` | `1000ms` | Atmospheric effects, slow reveals. |

---

## Easing Functions

| Name | CSS Variable | Curve |
|---|---|---|
| Base | `--timing-base` | `cubic-bezier(0.4, 0, 0.2, 1)` |
| Authentic | `--timing-authentic` | `cubic-bezier(0.4, 0, 0.2, 1)` |
| In | `--timing-in` | `cubic-bezier(0.4, 0, 1, 1)` |
| Out | `--timing-out` | `cubic-bezier(0, 0, 0.2, 1)` |
| In-Out | `--timing-in-out` | `cubic-bezier(0.4, 0, 0.2, 1)` |

## Spring Protocols

| Vibe | Stiffness | Damping | Mass | Description |
|---|---|---|---|---|
| **Bouncy** | `400` | `10` | `1` | High energy, elastic feedback. |
| **Smooth** | `260` | `20` | `1` | Default, responsive, and stable. |
| **Snappy** | `300` | `30` | `1` | Quick arrival with minimal oscillation. |
| **Gentle** | `100` | `15` | `1` | Soft, atmospheric transitions. |
