# Branding

The **AA** mark: two initials crossed by a lightning bolt. It comes in one-color marks that follow the theme, and brand-color icons that never change.

---

## One-color marks

`LOGO_MAIN` and `LOGO_ALT` use `fill="currentColor"`, so they take the text color around them. Set them in `foreground`; they stay visible in every vibe and mode.

## Brand-color icons

The favicons and app icons keep the brand blue `#027fcc` and yellow `#ffd42a` in every theme. Don't retint them to tokens. They're shown on white, the way browsers and launchers usually display them.

<div className="sb-unstyled my-6 grid grid-cols-2 gap-4 lg:grid-cols-4">
  {[
    ['FAVICON_MAIN', FAVICON_MAIN, 'Rounded square', 'rounded-card'],
    ['FAVICON_ALT', FAVICON_ALT, 'Transparent mark', 'rounded-card'],
    ['ICON_MAIN', ICON_MAIN, 'Circular app icon', 'rounded-full'],
    ['ICON_ALT', ICON_ALT, 'Circular, alternate', 'rounded-full'],
  ].map(([name, svg, use, shape]) => (
    <figure key={name} className="flex flex-col items-center gap-2">
      <div className={`border-rule flex aspect-square w-full max-w-36 items-center justify-center border bg-white p-4 ${shape}`} role="img" aria-label={`${name} icon`}>
        <div className="h-full w-full" dangerouslySetInnerHTML={{ __html: svg }} />
      </div>
      <figcaption className="text-center">
        <code className="text-foreground font-mono text-xs">{name}</code>
        <span className="text-muted-foreground block text-xs">{use}</span>
      </figcaption>
    </figure>
  ))}
</div>

The `azds` CLI in `@aazucena/design-system` generates the favicon suite and manifest into `dist/favicons/`: run `pnpm --filter @aazucena/design-system ds favicons default FAVICON_MAIN ./dist` (or `ds:sync` for CSS, Figma variables and favicons together).

## Name

- Running text: lowercase **aazucena**.
- Next to the logo: **AAZUCENA**.
- Avoid **Aazucena** unless a platform forces title case.

More in [Writing](?path=/docs/docs-writing--docs#capitalization).
