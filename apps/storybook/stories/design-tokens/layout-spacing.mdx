# Layout & Spacing

Spacing runs on a 4px grid. On top of it, Avra fixes a few density values so panels and controls line up across apps.

---

## Density

| Token | Value | Use |
|---|---|---|
| `--control-sm` | 30px | Compact controls in dense tables and toolbars (`h-control-sm`) |
| `--control-md` | 36px | Default buttons, inputs, selects (`h-control`) |
| `--control-lg` | 44px | Primary actions and touch-first layouts (`h-control-lg`) |
| `--row-height` | 36px | Table and list rows |
| `--panel-padding` | 20px | Inside every panel (`p-panel`) |
| `--panel-header` | 32px | The micro-label header strip |
| `--layout-gutter` | 24px | Between panels in a grid |

## Breakpoints

| Token | Value | Target |
|---|---|---|
| `xs` | `480px` | Small mobile devices |
| `sm` | `640px` | Large mobile / Small tablets |
| `md` | `768px` | Tablets (Portrait) |
| `lg` | `1024px` | Tablets (Landscape) / Small Laptops |
| `xl` | `1280px` | Standard Desktops |
| `2xl` | `1536px` | High-resolution displays |

Design phone layouts for 390px with a 16px side gutter, and check that nothing scrolls sideways.
