# Themes

A vibe recolors Avra's roles for a season or a style, and may swap the heading font (Playfair Display or Fira Code). Shape and density never change: every vibe keeps the 6px panels, 4px controls and 30/36/44 control heights. Body text is Fira Sans in every vibe.

Each row below applies the vibe with `ThemeManager` to its own container and reads the values back, so the swatches always match the code. To see a vibe on real components, pick it in the **Vibe** toolbar. The [vibe matrix](?path=/story/design-tokens-vibes-matrix--light) checks text contrast for every vibe in both modes.
