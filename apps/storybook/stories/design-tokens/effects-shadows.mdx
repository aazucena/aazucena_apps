# Shape & Elevation

Avra has two radii, separates layers by tone, and uses no shadows or blur on any component. Every vibe keeps this shape.

---

## Radius

| Token | Value | Used by |
|---|---|---|
| `--radius-card` | 6px | Panels, cards, dialogs, sheets |
| `--radius-control` | 4px | Buttons, inputs, selects, popovers, tooltips, menu items |
| `--radius-badge` | 4px | Badges and chips (square, not pills) |
| `--radius-progress` | 9999px | Progress tracks only |

The Tailwind utilities are `rounded-card` and `rounded-control`. The older scale (`--radius-sm` 4px, `--radius-md`/`--radius-lg` 8px, `--radius-xl` 12px, `--radius-2xl` 16px) is still generated for backward compatibility; new components don't use it.

---

## Elevation by tone

Layers step up in tone instead of casting shadows.

| Layer | Token | Example |
|---|---|---|
| Page | `--background` | The canvas |
| Content | `--panel` | Cards, panels, sidebars |
| Raised and overlays | `--panel-raised` | Popovers, menus, selects, secondary buttons |
| Interaction | `--state` | Hover, focus, selected rows |
| Modal backdrop | `--scrim` | Behind dialogs and sheets (background at 60%) |

Overlays add a 1px `--rule` border so they read as separate from the panel beneath.

---

## Shadows and blur

`--shadow` resolves to `none` and `--backdrop-blur` to `none` in the default vibe. The shadow scale (`--shadow-sm` to `--shadow-2xl`, `--shadow-inner`) is still generated for apps that haven't migrated, but no `@aazucena/ui` component uses it.

The **glass** variants use `--panel-glass`, the panel color at 70% opacity, with a 1px rule. There's no blur behind it, so check text contrast against whatever sits underneath.
