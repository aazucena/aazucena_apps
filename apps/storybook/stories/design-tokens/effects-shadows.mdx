# Effects & Shadows

The **@aazucena** effects system defines the tactile and material quality of the interface. It orchestrates volumetric depth through shadows, geometry through radii, and atmospheric density through blurs.

---

## Technical Specifications

### Elevation & Shadows
| Token | CSS Variable | Visual Depth |
|---|---|---|
| Small | `--shadow-sm` | Subtle elevation for small interactive elements. |
| Medium | `--shadow-md` | Standard card and component elevation. |
| Large | `--shadow-lg` | Elevated menus and distinct surface layers. |
| Extra Large | `--shadow-xl` | High elevation for popovers and overlays. |
| 2X Large | `--shadow-2xl` | Maximum elevation for global modals. |
| Inner | `--shadow-inner` | Inset depth for form fields and wells. |

### Surface Radii
| Token | CSS Variable | Default Value |
|---|---|---|
| Small | `--radius-sm` | `0.25rem` (4px) |
| Medium | `--radius-md` | `0.5rem` (8px) |
| Large | `--radius-lg` | `0.5rem` (8px) |
| Extra Large | `--radius-xl` | `0.75rem` (12px) |
| Pill | `--radius-badge` | `9999px` |

### Atmospheric Blurs
| Property | CSS Variable | Description |
|---|---|---|
| Backdrop Blur | `--backdrop-blur` | Standard refraction for toolbars and overlays. |
| Card Blur | `--card-blur` | Heavy material refraction for primary content cards. |
| Glow Color | `--glow-color` | Light-emitting accent used for depth enhancement. |
