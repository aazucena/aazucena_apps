# Design Tokens

Tokens are the named values behind every Avra component: colors, type, spacing, shape, motion and layers. `@aazucena/design-system` defines them in TypeScript and generates `css-vars.css`; the Figma variables use the same names.

---

## Three layers

| Layer | Example | Who uses it |
|---|---|---|
| **Palette** | `--ink-900`, `--signal-700`, `--zinc-400` | Vibe definitions only. Components never reference palette colors. |
| **Roles** | `--panel`, `--signal`, `--alert`, `--control-md` | Components, through utilities like `bg-panel` and `h-control`. |
| **Vibes** | `christmas`, `halloween`, `minimal` | Reassign the color roles for light and dark. Shape and density stay the same. |

A raw palette value becomes a role in the vibe definition (`panel: getColor('ink', 50)`), and a component uses the role (`bg-panel`). Changing a vibe recolors every component without touching component code.
