# Colors

Components use **roles**, not palette colors. A role names a job (`panel`, `signal`, `alert`); each vibe and mode assigns it a color. The swatches below read the live values, so the light/dark and **Vibe** toolbar change them.

## Derived aliases

The shadcn names exist so third-party and older components keep working. They point at the roles above; new code uses the roles.

| Alias | Resolves to |
|---|---|
| `--primary`, `--ring`, `--accent` | `signal` |
| `--card` | `panel` |
| `--popover`, `--muted` | `panel-raised` |
| `--border` | `rule` |
| `--input` | `rule-strong` |
| `--destructive` | `alert` |
| `--base`, `--elevated`, `--floating` | `background`, `panel`, `panel-raised` (legacy elevation names) |

The palette scales (`--zinc-*`, `--blue-*`, and the rest) are still generated for vibes to build from. Components don't use them directly; the `ui-token-usage` test enforces that.
