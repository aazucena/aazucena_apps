## Semantic Tokens

| Token | CSS Variable | Purpose |
|---|---|---|
| Primary | `--primary` | Main action color, brand identity. |
| Secondary | `--secondary` | Supporting accents, secondary actions. |
| Background | `--background` | Main application backdrop. |
| Surface Base | `--base` | Lowest elevation layer (e.g., page body). |
| Surface Elevated | `--elevated` | Mid elevation layer (e.g., cards, sidebars). |
| Surface Floating | `--floating` | Top elevation layer (e.g., modals, tooltips). |
| Foreground | `--foreground` | Primary text and high-contrast elements. |
| Muted Foreground | `--muted-foreground` | Secondary text and deactivated states. |
