# Layering & Z-Index

Our layering system enforces a strict volumetric hierarchy, ensuring that interaction depth is predictable and performant.

---

## The Hierarchy

| Tier | CSS Variable | Implementation |
|---|---|---|
| Base | `--z-base` | Content and standard layouts. |
| Dock | `--z-dock` | Navigation and toolbars. |
| Modal | `--z-modal` | Critical interaction layers. |
| Tooltip | `--z-tooltip` | Ephemeral contextual data. |
| Max | `--z-max` | Safety layer for absolute priority. |
