# Typography

Two families do the work: **Fira Sans** for reading and **Fira Code** for labels, data and code. Some vibes set headings in Playfair Display or Fira Code; body text stays Fira Sans everywhere.

---

## Families

| Role | Family | Token | Use |
|---|---|---|---|
| Body | Fira Sans | `--font-body` | Prose, controls, table cells |
| Headings | Fira Sans (vibe can change) | `--font-heading` | Page and section titles |
| Mono | Fira Code | `font-mono` | Panel labels, timestamps, IDs, values in tables, code |
| Serif | Playfair Display | `font-serif` | Headings in the Autumn, Christmas, Easter, Hoyoverse, Lunar New Year, Nature, New Year's, Northern Lights and Valentine's vibes |

## Scale

The `@aazucena/design-system` Tailwind preset sets its own scale, one step smaller than stock Tailwind: `text-xs` is 10px, not 12px. Storybook and `@aazucena/ui` use the preset.

| Utility | Size / line height | Use |
|---|---|---|
| `text-xs` | 10 / 16px | Micro-labels and badges only |
| `text-sm` | 12 / 20px | Captions, timestamps, table metadata |
| `text-base` | 14 / 24px | Body text, controls, table cells |
| `text-lg` | 16 / 28px | Lead paragraphs |
| `text-xl` | 18 / 28px | Card titles |
| `text-2xl` | 20 / 32px | Section titles |
| `text-3xl` | 24 / 36px | Page titles |
| `text-4xl` | 30 / 40px | Metric values |
| `text-5xl` | 36px | Display metrics |
| `text-6xl` | 48px | Hero values |

There are also named sizes: `text-h1` (30px) to `text-h6` (14px), `text-body` (14px) and `text-caption` (12px).

Keep reading text at 12px (`text-sm`) or larger. 10px is for the `micro-label` utility (uppercase, 0.2em tracking, Fira Code) and badges.

**Known gap:** apps that don't load the preset, such as `apps/analytics` today, get stock Tailwind sizes, so the same component renders one step larger there than in Storybook.

## Weights

| Weight | Use |
|---|---|
| 300 Light | Display values (`12,480`) and the default vibe's titles (`--font-title-weight`) |
| 400 Normal | Body text |
| 500 Medium | Labels, active nav items, table headers |
| 600 Semibold | Subheadings |
| 700 Bold | Page headings in prose |

Heavier weights (800, 900) are loaded but have no role in Avra 0.2.

## Labels

`micro-label` is the panel header style: `TRAFFIC // 30D`. Write the text in normal case in the source (`Traffic // 30d`) and let the utility uppercase it; some screen readers read all-caps words as abbreviations.
