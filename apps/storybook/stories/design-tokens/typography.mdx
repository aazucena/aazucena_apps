  from: number,
  to: number,
  duration: number,
  easing: EasingFn,
  onUpdate: (value: number) => void,
): () => void {
  const start = performance.now();
  let raf: number;

    onUpdate(lerp(from, to, easing(t)));

  };

  return () => cancelAnimationFrame(raf);
}`}

## Font Families

| Role | Font Family | Strategic Usage |
|---|---|---|
| **Sans** | `Fira Sans` | Primary readable content, UI labels, and action states. |
| **Mono** | `Fira Code` | Technical telemetry, system logs, and code-based intelligence. |
| **Serif** | `Playfair Display` | High-level display titles and editorial narrative accents. |

---

## Technical Specifications

### Font Weights
| Name | Weight | Role |
|---|---|---|
| Light | `300` | De-emphasized metadata and secondary descriptions. |
| Normal | `400` | Primary content and standard UI components. |
| Medium | `500` | Accented labels and active UI states. |
| Semibold | `600` | Subheadings and emphasized UI labels. |
| Bold | `700` | Primary headings and section titles. |
| Black | `800` | High-impact display and dashboard values. |
| Extra Bold | `900` | Maximum impact display elements. |

### System Dynamics
| Property | Implementation |
|---|---|
| **Grid Alignment** | All text is aligned to a 4px baseline grid to ensure vertical rhythm. |
| **Vibe Mapping** | `--font-heading` and `--font-body` are reassigned per-vibe. |
| **Letter Spacing** | Adjusted dynamically per-vibe to optimize for "Technical" vs "Editorial" personality. |
