New `@aazucena/ui/structure.css` holds the stacking, density and motion tokens that ui components read through `var()`. An app that renders ui components without the full `css-vars.css` imports it, so `z-(--z-modal)` and `duration-(--motion-base)` resolve. The portfolio now does; without it the z-index tiers resolved to `auto` there. The file is generated by `generateStructuralCss()` (`pnpm --filter @aazucena/design-system ds:structure`) and a test keeps it current.
