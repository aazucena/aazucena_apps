## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Email **aldrin@aazucena.com** with the subject line: `Security Vulnerability - @aazucena/<package>`

Please include:
- Package name and version
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Your suggested fix (optional)

I aim to acknowledge reports within **48 hours** and resolve critical vulnerabilities within **14 days**.
